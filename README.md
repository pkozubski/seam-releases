# Seam downloads

Seam joins a Mac and a Windows PC on your local network: one keyboard and mouse, a shared clipboard,
Mac audio on the PC, and windows in both directions.

**Website:** [seamdesk.app](https://seamdesk.app)

Download the latest version from [Releases](https://github.com/pkozubski/seam-releases/releases/latest):

- macOS 14.2+ (Apple Silicon and Intel): `Seam-macOS.zip`
- Windows 10/11 x64: `Seam-Windows-x64.exe`

Every file has a SHA-256 checksum (`SHA256SUMS.txt`) and an ECDSA signature (`.sig`) that the app checks before installing an update.
This repository only hosts releases; support: support@seamdesk.app.
